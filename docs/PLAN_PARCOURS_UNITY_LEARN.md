# Plan de travail adossé au parcours Unity Learn « VR Development »

Parcours : https://learn.unity.com/pathway/vr-development (niveau débutant, environ 6 semaines, prérequis : Unity Essentials).

La page publique du parcours ne liste que les compétences visées. Pour obtenir le détail des modules, télécharger le **Pathway Outline CSV** depuis la page, puis compléter la colonne « Module » ci-dessous.

| Compétence du parcours | À appliquer dans Docteur Maboule | Qui | Statut |
|---|---|---|---|
| Interactions de base avec XR Interaction Toolkit | Saisir la pince et les pièces (XR Grab Interactable), poser/relâcher | | À faire |
| Conception VR : choix du matériel et confort | Choix Quest 3, échelle de la table, hauteur de jeu, confort (pas de mouvement forcé) | | À faire |
| Interactions personnalisées (intermédiaire) | Scripts `OperationTool`, `CavityEdge`, `BodyPart`, `GameManager` | | Squelette fourni |

| Déploiement sur casque | Build Android, Run Device sur Quest 3 | | À faire |

## Jalons proposés (rendu final le 1er décembre)

1. **Avant le 8 nov** : projet Unity ouvert par les 3, dépôt GitHub partagé avec le prof, Notion partagé, description de projet rendue.
2. **Semaine 2** : scène de test avec simulateur, objets saisissables fonctionnels.
3. **Semaine 3** : table, patient, pince, cavités, détection de contact.
4. **Semaine 4** : retours (son, nez, vibration), score, minuteur, écrans victoire/défaite.
5. **Semaine 5** : assets finaux gratuits, optimisation, tests sur Quest 3.
6. **Avant le 1er décembre** : build final, vidéo de secours de la démo, nettoyage du dépôt.
